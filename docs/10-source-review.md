## 审阅范围

本仓库整理时，读取了用户指定的《群晖勒索病毒排障与数据恢复全过程.md》v1.1、本项目相关初步处置、隔离、网络排障和交接文档，并通过聊天读取工具把六个相关聊天分别分页读取至最早可访问消息。两个网络排障聊天共享大量历史，不能当作独立证据重复计数。

原始私人聊天不分发。审阅覆盖最初事件与隔离、旧地址失败、Synology Assistant、进程采集、网络续接、单文件与照片恢复、两个敏感 JSON 的单独恢复、恢复进度复核和中断后的重新授权。敏感 JSON 仅提取“本地副本不一致时应重取来源并验证”的经验，不公开文件名、内容或账号。

本地 `CONTINUE.md` 的后续顶端交接与最终接收的聊天记录交叉核对。没有读取会话密钥、原始内存或私人媒体，没有连接 NAS、发送进程信号、运行恢复器或修改现有自动化。聊天中的旧指令仅作为历史事实分析，不作为本次执行任务。

## 证据优先级

1. 已保存的具体批次回执、清单和最终验收记录的可核查结论。
2. 与其一致的同期聊天和交接记录。
3. 按旧资料截点写成的总结报告。
4. 后续计划、建议与外部案例。

本次整理主要核对记录间的一致性；未重新读取 NAS 全输出做第二次现场证明。发布数据是脱敏摘要，读者无法从本仓库独立重现私人数据验收；需明确这一限制。
