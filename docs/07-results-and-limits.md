## 验证等级不能混用

| 证据 | 能支持的结论 | 不能推出 |
|---|---|---|
| 传输/副本 SHA 一致 | 与指定来源字节一致 | 来源等于感染前原件 |
| 归档成员、内容与元数据通过 | 保存指定范围的原件 | 已有独立设备备份 |
| key record 匹配 | 候选与尾记录结构一致 | 正文全文认证成功 |
| 输出全量重读 SHA | 落盘输出与本次生成记录一致 | 与历史原件一致 |
| 容器可解析 | 已查结构可读取 | 所有轨道或像素完整 |
| 完整解码 | 指定解码路径读取成功 | 历史字节完全一致或所有辅助图通过 |
| 历史原件完整 SHA | 指定文件与该精确原件相同 | 其他所有文件也正确 |
| 应用实际验收 | 指定操作在测试环境可用 | 系统安全或全部业务一致 |

本仓库的清单工具只支持路径/类型/字节比较，不承担 ACL/xattr、硬链接拓扑、Btrfs csum 或应用验收。
